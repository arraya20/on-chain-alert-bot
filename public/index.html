What this actually does

  • Native transfers are read by scanning blocks; native PROS moves emit no log, so eth_getLogs cannot see them.
  • Token transfers come from Transfer logs, with the topic derived from the signature rather than copied.
  • Paused state is an eth_call of paused(), so it reflects the contract, not a cached dashboard.
  • A rule that cannot be measured shows ERROR, never OK. Silence is not health.
  • Delivery runs in the watcher (scripts/watch.mjs), not from this page. A public endpoint that sends messages is a spam cannon.
